\section{Conclusion}
\label{sec:conclusion}

We measured how much an edit to an earlier, updated value shifts a language model's candidate scores for a query about the associated entity, relative to a query about the other entity. In seven models from five families this sensitivity depends more on where and how the value is mentioned than on whether the value was ever assigned to the queried attribute: among the tested contrasts, mention order produces the largest changes in every model, an entity mention outweighs a superseded assignment in six of the seven, and relation status ranges from a negative effect in Mistral-7B to about a quarter of superseded relevance in Qwen3-14B. Finer order and marker effects differ between models. Because the screened models have near-ceiling current-candidate ranking, these are statements about candidate scores, not generated answers. Studies of how models handle updated information should control the construction and order of earlier mentions, and report results per model, before attributing residual sensitivity to obsolete assignments.
