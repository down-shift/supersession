\section{Conclusion}
\label{sec:conclusion}

We measured how much an edit to an earlier, updated value shifts a language model's candidate scores for a query about the associated entity, relative to a query about the other entity. In Qwen3-8B and Gemma 3 4B this sensitivity depends more on how and where the value is mentioned (with the entity or alone, in which relative position, with or without \lit{Previously}) than on whether the value was ever assigned to the queried attribute, which changes it little on average. The directions of the finer order and marker effects differ between models, and name--value proximity does not explain why entity mentions outweigh superseded assignments. In Qwen, the small average effect of relation status hides a positive effect of having been the queried attribute and a negative effect of having been updated, and sensitivity to the most recent superseded value grows with the number of updates; Gemma shows neither pattern clearly. Because the models answer at ceiling, these are statements about scores, not answers. Studies of how models handle updated information should control the construction and order of earlier mentions, and report results per model, before attributing residual sensitivity to obsolete assignments.
