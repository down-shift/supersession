\begin{abstract}
When a context updates a fact, does the earlier value still shape a language model's answer scores? We replace a historical value in two-entity histories, keeping current assignments fixed, and measure how much more this shifts candidate scores for a query about the associated entity than for a query about the other entity. In Qwen3-8B and Gemma 3 4B, tested prompt constructions and mention order change this query-specific score sensitivity. The average superseded-minus-other-attribute contrast is 0.314 nats in Qwen and 0.004 in Gemma, but Qwen's attribute-specific contrasts vary in sign. Entity-mention relevance exceeds superseded relevance on average in both models, while its aligned-versus-reversed order effect points in opposite directions across models. Unassigned-value relevance reverses sign across order groups in both. A separate 24-history confirmation finds that adding the explicit marker \lit{Previously} lowers relevance; the marker-by-construction interaction is positive for Qwen and unresolved for Gemma. These contrasts show sensitivity to the tested prompt constructions, not an isolated obsolete-assignment mechanism. The measure uses bounded candidate scores: the current value stays top-ranked in every superseded trial, and effects on generated answers below ceiling are untested.
\end{abstract}
