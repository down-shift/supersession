\begin{abstract}
When a context updates a fact, does the earlier value still shape a language model's answer scores, and why? We replace a historical value in two-entity histories, keeping current assignments fixed, and measure how much more this shifts candidate scores for a query about the associated entity than for a query about the other entity. Across six prompt constructions crossed with mention order in Qwen3-8B and Gemma 3 4B, this sensitivity is governed by surface association---how a value is mentioned, where it appears relative to the entities, and whether it is marked as past---and only weakly by whether it was ever assigned to the queried attribute. Being an updated value of the queried attribute, rather than of another attribute, changes sensitivity by 0.314 nats in Qwen and 0.004 in Gemma; mentioning it in a note about the entity instead raises sensitivity by 3.504 and 2.589 nats. Never-assigned values are credited to whichever entity shares their position, so their effect reverses with mention order; in a 24-history follow-up, the marker \lit{Previously} lowered sensitivity in both constructions tested. The measure uses bounded candidate scores: the current value stays top-ranked in every superseded trial, and effects on generated answers below ceiling are untested.
\end{abstract}
