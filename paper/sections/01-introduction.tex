\section{Introduction}
\label{sec:introduction}

Conversations and documents often update a fact while leaving its earlier version in view. A user's preference changes, an object moves, a task variable receives a new value. A language model can answer with the current value and still be influenced by the old one: its scores for candidate answers may shift when the old value changes, even though the top answer does not. This paper asks what governs that residual sensitivity.

Consider a history from our main experiment:

\begin{prompt}
Previously, Nora’s badge was amber.
Previously, Liam’s badge was coral.
Currently, Nora’s badge is jade.
Currently, Liam’s badge is pearl.
What is Nora’s current badge?
Respond with only the value, with no explanation.
\end{prompt}

The correct answer is \lit{jade}. Suppose we replace the earlier \lit{amber} with \lit{violet} and leave the other prompt content fixed. The edit can shift the model's scores for \lit{violet} relative to \lit{amber}. If the shift is larger when the question asks about Nora than when it asks about Liam, the score change is query-specific. We call the difference between these two shifts \emph{query relevance}, $R$ (Section~\ref{sec:edits}).

A positive $R$ for the history above could arise for several reasons. The model may represent that \lit{amber} \emph{was} Nora's badge, a superseded assignment to the queried attribute. It may associate \lit{amber} with Nora because they appear in the same sentence, or link them by position because both come first in their blocks. The explicit marker \lit{Previously} could also affect the score contrast. We compare prompt constructions that hold some features fixed while changing others, and cross them with historical and current entity order. The contrasts constrain possible explanations but do not independently identify each factor.

In seven models from five families, \textbf{query-specific score sensitivity to a historical value depends more on where and how the value is mentioned than on whether it was ever assigned to the queried attribute.} Reversing mention order changes $R$ for a never-assigned value by 4.970 to 11.837 nats in every model, more than relation status changes it in any model, which ranges from $-1.305$ nats in Mistral-7B to 1.162 in Qwen3-14B. Mentioning the value with the entity instead of as a superseded assignment raises $R$ in six of the seven models; in Mistral-7B the difference is unresolved and its sign depends on mention order. That gap exceeds relation status in five models, not resolvably in Granite-3.1-8B and Mistral-7B (Table~\ref{tab:models}). Relation status here is the contrast between superseded and other-attribute assignment, which changes both the attribute and whether the current block contradicts the earlier value. These comparisons do not rank all determinants of sensitivity; they compare the tested contrasts.

In the two models we study most closely, Qwen3-8B and Gemma 3 4B, relation status changes $R$ by 0.314 and 0.004 nats, and an entity mention exceeds a superseded assignment by 3.504 and 2.589 nats, or 1.293 and 0.367 with the marker and name--value distance matched. Values assigned to no one are credited to whichever entity occupies the same relative position, adding the prefix \lit{Previously,} lowers $R$, and finer order and marker effects differ between the two models. The two models narrowly excluded by the competence screen show the same ordering.

Our contributions are:
\begin{enumerate}
\item A counterfactual measure of query-specific sensitivity to a historical value, applied to six prompt constructions crossed with independently varied historical and current mention order (Sections~\ref{sec:task}--\ref{sec:setup}).
\item A comparison of the prompt features that change this sensitivity: mention order produces larger changes than the relation-status contrast in every screened model; the entity-mention gap exceeds that contrast in five of seven; finer effects depend on the model (Section~\ref{sec:main-findings}, Figure~\ref{fig:decomposition}).
\item Order-stratified evidence that never-assigned values are credited by position, with effects that cancel when orders are averaged (Section~\ref{sec:order}).
\item A second main experiment on the prefix \lit{Previously,} (96 histories); three controlled follow-ups, on name--value distance, on whether the other attribute is also updated, and on update chains (a development run and a score-only run); an extension of Experiment 1 to five additional screened models, giving seven models from five families; and an exploratory generation study in OLMo-2. In Qwen a separate update-control design finds a positive attribute effect and a negative update effect; in a development run of update chains every generated answer was correct, and in an independent score-only run Qwen's sensitivity to the immediately superseded value grows with chain depth (Sections~\ref{sec:marker-results}--\ref{sec:additional-models}).
\end{enumerate}
