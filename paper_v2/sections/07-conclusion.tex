\section{Conclusion}
\label{sec:conclusion}

In five open models that report the current and the initial state of a record correctly, an obsolete state
still shifts routing preferences toward the action it implies. Those shifts changed decisions mainly when
another cue in the record agreed: net switch rates were 0.143--0.233 when the other entity's current state
implied the wrong action, in Qwen3-8B 0.031 when it did not, and in both Qwen3 models zero with thinking enabled. The
interference requires neither supersession nor assignment to the queried attribute: the same word mentioned
in passing by the same entity shifted preferences in every model and changed more decisions than the
superseded assignment in two. Retrieval-score sensitivity did not improve prediction beyond the specified
pre-decision features. Stale-context benchmarks and mitigations should therefore be evaluated with
incidental-mention controls, with the other cues in the record reported or varied, and with decision-level
outcomes, not only retrieval accuracy. \modelcountconclusion
