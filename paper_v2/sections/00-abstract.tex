\begin{abstract}
A model can retrieve the current value of an updated record correctly while an old value still shifts
its decision preferences. We test whether this interference depends on supersession. In synthetic
routing and access-control records, paired edits change a historical state word while holding the
current state, policy and correct action fixed. Matched controls place the edited word in an updated
unrelated attribute, an incidental entity mention, or an unattached position. Across five open models tested on held-out confirmation wording,
obsolete states shifted routing preferences toward the action they imply (1.085--4.785 nats on
cells selected by the frozen gate). Post hoc checks retain the effect on histories with correct current and
initial retrieval and correct current-only decisions. Incidental mentions also shifted preferences
in every model. An exploratory Qwen3-8B comparison found fewer generated switches when the other
entity's state supported the correct action, but different histories prevent isolating cue agreement.
Thinking-enabled generation produced no superseded switches in either Qwen3 model. These results
show that interference requires neither supersession nor assignment to the queried attribute.
Matched lexical controls and separate measures of decision preferences and generated answers are
therefore needed to characterize interference beyond retrieval accuracy.\footnote{Code is available at \url{https://anonymous.4open.science/r/obsolete-BA55/}.}
\end{abstract}
