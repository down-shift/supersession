\begin{abstract}
A model that reads an updated record can report the current value correctly and still let the old value
shape its decision. We test whether this happens, and whether it depends on the old value having been
superseded. In synthetic routing and access-control records, the current state, the policy and the
correct action are fixed while one obsolete state is edited to imply the correct or the wrong action.
Matched controls place the same word as an updated assignment of an unrelated attribute, as a word the
entity merely mentioned, or as an unattached word. In a frozen confirmation on held-out wording
(Qwen3-8B), we kept the routing histories in which the model retrieved the current and initial states and
decided correctly without history (348 of 384). There, the obsolete state gave a net switch rate toward
the wrong action of 0.158 (58 histories switched to wrong, 3 to correct). Across routing histories, a
superseded assignment added 1.224 nats of wrong-action preference over an updated unrelated attribute.
An incidental mention of the same word by the same entity moved decisions at least as much (net switch
rate 0.278). \modelcountsentence
\end{abstract}
